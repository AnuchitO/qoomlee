# QOOMLEE - Documentation Directory

## Overview
This directory contains all business and technical documentation for the Qoomlee Airline System. These documents define the business case, system requirements, and technical specifications.

## File Categories

### Business Strategy
- **Qoomlee_Route_Market_Analysis.md** - Business case and market opportunity analysis for connecting Southeast Asian tier-2 cities to Australian gateways
  - Market opportunity and growth projections
  - Competitive positioning and value proposition
  - Target customer segments and route strategy

### System Definition
- **Qoomlee_Definition.md** - Core system definition and operational workflow
  - System types and functionality overview
  - Core modules and their responsibilities
  - Database entities and relationships
  - Passenger and admin workflows

### Requirements
- **Qoomlee_MVP_PRD.docx** - Product Requirements Document for the Minimum Viable Product
  - MVP feature set and scope
  - User stories and acceptance criteria
  - Success metrics and KPIs
  - Out of scope items for MVP

### Technical Specifications
- **Qoomlee_DB_Schema_API_Contract.docx** - Database schema and API contract specifications
  - Database table structures and relationships
  - API endpoints and request/response formats
  - Data validation rules and constraints
  - Integration specifications

### UI/UX Design
- **stitch_ui_prompt.md** - UI design prompts for generating mockups with Stitch tool
  - Screen specifications and requirements
  - Design system implementation guidelines
  - User interaction patterns
  - Visual hierarchy and layout requirements

## How to Navigate
1. **Understand the business:** Start with `Qoomlee_Route_Market_Analysis.md`
2. **Learn the system:** Read `Qoomlee_Definition.md` for core concepts
3. **Define requirements:** Review `Qoomlee_MVP_PRD.docx` for MVP scope
4. **Technical details:** Examine `Qoomlee_DB_Schema_API_Contract.docx` for implementation details
5. **Design guidance:** Use `stitch_ui_prompt.md` for UI development

## Key Concepts
- **Hybrid Airline Model:** LCC comfort+ concept targeting middle-income travelers
- **MVP Focus:** Core functionality prioritized over advanced features
- **Asia-Pacific Focus:** Serving underconnected markets between Southeast Asia and Australia
- **Digital-First:** Emphasis on online booking and self-service features
