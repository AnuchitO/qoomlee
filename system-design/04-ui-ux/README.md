# QOOMLEE - UI/UX Directory

## Overview
This directory contains all user interface and user experience design materials for the Qoomlee Airline System. These files define the visual design system, user interactions, and interface specifications.

## File Contents

### Design System
- **DESIGN.md** - Complete design system specification following Google's DESIGN.md format
  - Color palette and usage guidelines
  - Typography system and hierarchy
  - Spacing and layout principles
  - Component specifications and styles
  - Accessibility standards and requirements

### UI Design Materials
- **stitch_ui_prompt.md** - Prompt specifications for generating UI mockups with Google Stitch
  - Screen-by-screen design requirements
  - Interaction patterns and user flows
  - Visual design specifications
  - Responsive design considerations

- **ui_mockups.md** - Documentation of UI mockup concepts and design decisions
  - Wireframe concepts and layouts
  - User journey mapping
  - Design rationale and decisions
  - Feedback and iteration notes

## Design Principles

### Visual Identity
- **Brand Colors:** Sky blue (#0E70CA) primary, dark blue (#1A3557) secondary
- **Typography:** Clean, readable system fonts with proper hierarchy
- **Layout:** Consistent spacing and alignment based on 8px grid
- **Shapes:** Soft rounded corners for approachable feel

### User Experience
- **Mobile-First:** Designed primarily for mobile devices with responsive scaling
- **Intuitive Navigation:** Clear information architecture and navigation patterns
- **Accessibility:** WCAG 2.1 AA compliance for inclusive design
- **Performance:** Optimized for fast loading and smooth interactions

## Screen Specifications

### Core Screens
1. **Flight Search Screen** - Flight discovery and selection interface
2. **Booking Page** - Passenger information and booking completion
3. **Online Check-in Page** - Booking retrieval and check-in process
4. **Boarding Pass Screen** - Digital boarding pass display and sharing

### Component Library
- **Headers** - Consistent branding and navigation
- **Forms** - Standardized input fields and validation
- **Buttons** - Primary and secondary action styles
- **Cards** - Content grouping and information display
- **Navigation** - Bottom navigation for mobile accessibility

- Follow the design system specifications for consistency

## Key Concepts
- **Design System Approach** - Consistent visual language across all interfaces
- **Mobile-First Design** - Prioritizing mobile experience with responsive scaling
- **Accessibility Focus** - Inclusive design meeting WCAG standards
