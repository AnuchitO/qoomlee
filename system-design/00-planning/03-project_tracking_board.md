# QOOMLEE AIRLINE SYSTEM - PROJECT TRACKING BOARD

## PROJECT OVERVIEW
- **Project Name:** Qoomlee Airline System MVP
- **Objective:** Build an airline booking and check-in system for a hybrid (LCC comfort+) carrier connecting Southeast Asian tier-2 cities to Australian gateways
- **Timeline:** 8 weeks (MVP)
- **Team Structure:** Cross-functional team with developers, designers, QA, and product owner

## EPICS
1. **Authentication Epic** - User login and role-based access control
2. **Flight Management Epic** - Flight creation, schedules, aircraft management
3. **Booking Epic** - Passenger reservations, seat selection
4. **Payment Epic** - Payment processing, receipts, refunds
5. **Passenger Management Epic** - Passenger profiles, data management
6. **Check-in Epic** - Online/offline check-in functionality
7. **Boarding Pass Epic** - Generate, manage, and validate boarding passes
8. **UI/UX Epic** - Frontend development and user experience
